# AAIS Anonymous Suggestion Web
research

## Overview

The AAIS Anonymous Suggestion Web is a web-based platform designed to provide a safe and anonymous freedom wall for the AAIS community. The system allows students, teachers, staff, and administrators to express their suggestions, concerns, feedback, confessions, and appreciation messages without revealing their identity.

This platform aims to strengthen communication within the school and promote a more transparent, responsive, and student-centered environment.

---

## Objectives

- To provide a secure and anonymous platform for voicing concerns and suggestions.
- To encourage open communication within the school community.
- To help school administrators identify and address issues efficiently.
- To promote a culture where every voice is heard and valued.

---

## Target Users

- Students (Primary Users)
- Teachers
- School Staff
- School Administrators

---

## Key Features

### User Side:
- Anonymous message submission
- Message category selection:
  - Suggestions
  - Concerns
  - Confessions
  - Appreciation
  - Feedback
- Freedom wall display
- Inspirational quote header
- School logo display

### Admin Side:
- Secure admin login system
- Message approval system
- Message status management (e.g., Pending, Approved, Resolved)
- Monitoring and reviewing of submitted entries

---

## System Scope

The system focuses on internal school communication and is exclusively intended for the AAIS community.
